# Praktikum 2 - Objek Primitif

Nama: Khalitputra Afana
NPM: 140810240007

Program ini menggambar garis dan lingkaran dengan tiga algoritma garis (dasar, DDA, Bresenham)
dan tiga algoritma lingkaran (dasar, polar, Bresenham). Koordinat diatur dengan slider dan
hasil tiap algoritma ditampilkan pada kanvas terpisah.

## Menjalankan

1. Buka `praktikum2.slnx` di Visual Studio 2022 atau VS Code (dengan C# Dev Kit).
2. Build project.
3. Jalankan program.

## Isi

- Prak.2.1 - Implementasi algoritma garis dasar
- Prak.2.2 - Implementasi algoritma garis DDA
- Prak.2.3 - Implementasi algoritma garis Bresenham
- Prak.2.4 - Implementasi algoritma lingkaran dasar
- Prak.2.5 - Implementasi algoritma lingkaran polar
- Prak.2.6 - Implementasi algoritma lingkaran Bresenham
- Prak.2.7 - Integrasi semua algoritma dalam satu program
